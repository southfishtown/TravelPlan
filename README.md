## 🏨 全程精选奢享酒店

1. **釜山海云台万枫酒店 (Fairfield by Marriott Busan)**  
   * **入住时间：** 9月25日 - 9月28日（连住 3 晚）  
   * **位置亮点：** 坐落海云台核心，步行 3 分钟到沙滩，步行 4 分钟至传统海鲜市场，步行 10 分钟到蓝线公园尾浦站。
2. **首尔帕纳斯洲际酒店 (Grand InterContinental Seoul Parnas)**  
   * **入住时间：** 9月28日 - 10月2日（连住 4 晚）  
   * **位置亮点：** 江南三成洞奢华地标，地下直通 **Starfield COEX Mall**、**星空图书馆** 与 **地铁 2 号线三成站 / 9 号线奉恩寺站**；享行政酒廊尊属礼遇。
3. **郑州航空港万怡酒店 (Courtyard by Marriott Zhengzhou Airport)**  
   * **入住时间：** 10月2日 - 10月3日/4日（落地休整 1-2 晚）  
   * **位置亮点：** 离新郑机场 T2 仅 4 公里（车程 8 分钟），落地即刻洗漱安睡，避开深夜长途奔波。

## 🎒 行前必备 5 大核心核对清单 (Check-List)

1. **📄 1. 证件与入境红线：**
   * [x] **护照原件：** 有效期在 2025年4月以后（6个月以上），2页以上空白页。
   * [x] **韩国个签 (C-3-9)：** 提前办妥打印备用。
   * [x] **随身备黑色水笔：** 机上填写入境卡与海关申报单（英文/拼音大写填写）。
   * [x] **电子 Q-CODE：** 出发前 48 小时内填好生成二维码截图。
2. **🏨 2. 酒店与票务锁定：**
   * [x] **首尔洲际入住：** 下午 14:00 正常入住，从容享受 17:30 行政酒廊 Happy Hour！
   * [x] **郑州万怡接机预约：** 10/2 白天去电告知航班 22:45 落地并预约接机班车。
   * [x] **海滨列车车票：** 锁定 9/26 11:30-12:00 “松亭➔尾浦” 单程票，提前 15 分钟排队抢第一排海景座。
   * [x] **高铁车票凭证：** 保存 9/28 10:47 釜山➔13:25 水西车票截图，对号入座。
3. **📱 3. 手机网络与必备 App：**
   * [x] **流量卡 / eSIM：** 购买 8 天韩国无限流量卡或境外 eSIM。
   * [x] **Naver Map（中文版）：** 韩国核心导航神器（谷歌地图在韩无法步导）。
   * [x] **Kakao T / Uber：** 绑定国内外币信用卡叫车。
   * [x] **Papago 翻译官：** 拍照翻译菜单、药盒地道精准。
4. **💳 4. 货币支付与即时退税：**
   * [x] **韩元现金 (20-30万)：** 用于 T-Money 充值（只收现金）和市场小摊。
   * [x] **芯片外币信用卡：** Visa / Mastercard 芯片卡 1-2 张。
   * [x] **微信 / 支付宝：** 免税店、百货、便利店直接扫码支付。
   * [x] **随身带护照即时退税：** 满 1.5 万韩元专柜现场直接扣除免税。
5. **🔌 5. 行李穿搭与生活物品：**
   * [x] **德标/韩标插头 (4.8mm粗双圆孔)：** 国内扁头无法直接插入，必带！
   * [x] **自带一次性牙刷牙膏：** 韩国环保法禁止酒店免费提供。
   * [x] **初秋洋葱式叠穿：** 白天 24℃舒适，早晚 15℃，备轻薄防风外套。
   * [x] **轻便耐磨运动鞋：** 坡道台阶多，好走舒适是第一位。
   * [x] **常备应急药品：** 肠胃药、感冒药、创可贴。
